# MediKataru for pet

> 動物病院での説明を、家族みんなにわかる言葉で。

MediKataru（医療者の説明を患者・家族向けに要約するアプリ）を、**ペット・動物病院向け**に作り直した Web アプリです。
画面は HTML・CSS・JavaScript だけで作っています（ビルド不要）。

## できること

| 機能 | 内容 |
|---|---|
| 説明の記録 | 「準備 → 録音 → 確認」の3ステップ。ブラウザの音声認識（Chrome / Edge / Safari）で文字にする。直接入力・貼り付けも可。獣医師・スタッフの了承チェックがないと進めない |
| **今日の説明**（ご家族向け） | ボタン一つで、やさしい言葉のまとめを作成：ひとことで／こんな様子なら連絡／大事なこと／**お薬（何の薬・あげ方）**／おうちですること／予定／むずかしい言葉の意味／次に確認すること |
| **これまでの受診歴** | 同じ画面の切り替えボタン一つで表示。全受診の記録＋写真のメモから、AIが経過を1枚に：注意点（アレルギーなど）／続いている症状／今のお薬／予定／ワクチン・予防／体重の変化／受診の流れ。受診の一覧と、場所ごとの写真の並びも表示 |
| **日々の記録** | 1日1ページで、元気・食欲、日記、できごとの写真、ごはん・おやつ、サプリ・飲んでいるお薬、体重、飲んだ水、うんち（状態・回数・血や粘液）、散歩（犬のみ）を記録。入力すると自動で保存。「前の記録と同じ」でごはんをまとめて入れられる。一覧と体重のグラフつき |
| **日々の経過のまとめ（受診用）** | 期間（前回の受診から／7・14・30日）の記録を、ボタン一つでAIが獣医師向けにまとめる。体重の増減・水の平均・うんちの日数などの数字はアプリが計算して表示し、AIにも渡す。印刷・LINEで送る・コピーができる |
| **写真の記録** | カメラで皮膚・傷・できものなどを撮影。撮る場所（皮膚・耳・目・足など）を選ぶと、**前回同じ場所を撮った写真をうすく重ねて**、同じ角度・距離で撮れる。様子のメモ・撮影日を保存。**2枚を選んで「前と今」を並べてくらべる**機能つき |
| 受診と写真のひもづけ | 録音中に撮った写真や、まとめ画面で追加した写真は、その受診の記録に表示 |
| 家族への共有 | 「LINEで送る」「ほかの方法で送る」「文章をコピー」。表示中のまとめ（今日の説明／受診歴）を送る。写真ともとの説明は送らない |
| **ホーム画面に追加（PWA）** | スマホのホーム画面にアイコンを置いて、アプリのように全画面で使える。電波がなくても画面が開き、記録・写真を見られる（まとめるのは電波が必要）。最初の画面と設定に追加の手順を表示（Android は追加ボタン、iPhone は Safari の手順と「先にバックアップ」） |
| **管理者（医師）の確認と用語辞書** | まとめのとき、AIが言い換えに迷ったところ（言い換え・聞き取り・あいまいな指示）を自動で管理者に報告。名前・病院名・説明者・電話番号などは消して保存し、利用者の画面には出さない。管理者は「設定 → 管理者の方へ」から合言葉で開き、正しい言い換えを用語辞書に登録。辞書は次からのまとめでAIに渡される。モデルごとに「直した割合」も集計 |
| 読み上げ・印刷・文字サイズ | 「声で読み上げる」、印刷用の表示、文字の大きさ（標準・大・特大） |
| バックアップ | 設定画面から、写真も含めてファイルに書き出し・読み込み。**最後のバックアップ（なければ最初の記録）から30日たつと、最初の画面とペットのページの上にお知らせ**を出す（「今すぐバックアップ」で書き出し、「あとで」で30日間お休みして31日目にまた表示） |

### 元の MediKataru からの主な変更
- 「医療者向けサマリー（SOAP）」→「**これまでの受診歴**」に置き換え（ペットは複数の病院にかかることが人より少ないため、経過のまとめを優先）
- AI の出力を動物病院向けに変更：お薬のあげ方、おうちでのケア（シャンプー・エリザベスカラーなど）、ワクチン・予防、体重
- **写真の記録**を追加
- 配色を暖色（テラコッタ・アプリコット・クリーム）に、書体を丸みのある Zen Maru Gothic に変更。ダークモード対応

## しくみ

```
public/               画面（HTML・CSS・JavaScript、ビルド不要）
  index.html
  css/style.css       デザイン（色はすべて :root の変数で管理）
  js/app.js           画面の切り替えと各画面
  js/store.js         保存（ブラウザの IndexedDB）
  js/camera.js        カメラ撮影・写真の縮小・前回写真の重ね表示
  js/ui.js            小さな道具（ダイアログ・日付など）
  js/admin.js         管理者（医師）の確認画面
  js/daily.js         日々の記録・一覧と体重グラフ・日々の経過のまとめ
  js/backup.js        バックアップの書き出しと、30日ごとのお知らせ
  js/pwa.js           ホーム画面に追加の案内・Service Worker の登録
  sw.js               Service Worker（電波がなくても画面を開けるよう、画面のファイルを保管）
  manifest.webmanifest, icons/  ホーム画面のアプリの名前・アイコン
server.js             画面を配り、AI を呼ぶだけの小さなサーバー（Node.js 標準機能のみ）
lib/ai.js             Claude API の呼び出しとプロンプト
lib/schemas.js        まとめの出力の形（Zod）
lib/feedback.js       AIが迷ったところの保存・用語辞書（Turso / 手元のファイル）
```

- **記録と写真は、使っている端末のブラウザの中（IndexedDB）だけに保存**します。サーバーにはデータが残りません。そのためログイン機能はありません
- **写真はサーバーにも AI にも送りません**。AI に送るのは「まとめる」を押したときの説明の文字と、受診歴のまとめのときの写真のメモ（文字）だけです
- AI のキー（`ANTHROPIC_API_KEY`）はサーバーだけが持ち、ブラウザには渡しません
- AI は元の MediKataru と同じく `claude-sonnet-5-5`・考える深さ `medium`（構造化出力・安全分類器で止められたときの自動切り替えつき）。`ANTHROPIC_MODEL=claude-opus-5-5` で精度重視に変えられます
- キーが未設定でも動きます（まとめは「お試し表示」になります）

## 動かし方

Node.js 22 以上が必要です。

```bash
npm install
```

```bash
cp .env.example .env.local   # ANTHROPIC_API_KEY を書く
```

```bash
npm start                    # http://localhost:3000
```

> **カメラについて**：ブラウザの決まりで、画面内のカメラは `https://` か `localhost` で開いたときだけ使えます。
> それ以外（社内のIPアドレスなど）で開いた場合は、自動でスマホのカメラアプリ／写真の選択に切り替わります。

## 公開する（Render）

`render.yaml` を用意しています。Render の管理画面で「New → Blueprint」からこのリポジトリを選び、`ANTHROPIC_API_KEY` を入力すれば公開できます（https で公開されるため、スマホでもカメラが使えます）。
データベースは不要です。

## 注意（次の段階で検討すること）

- **データは端末ごと**：機種変更やブラウザのデータ削除で消えるため、設定画面のバックアップを案内しています。家族の複数端末で同じ記録を見たい場合は、アカウントとクラウド保存が必要
- **写真の AI 解析はしていません**：皮膚の状態を AI が判定すると「診断」に近づくため、あえて写真は記録・比較だけにしています
- AI のまとめは下書きです。診断や治療の判断には使わず、必ず獣医師に確認する旨を画面に表示しています

## 管理者（医師）の確認を使うための設定

Render の「Environment」に次の3つを入れます。

| 名前 | 中身 |
|---|---|
| `ADMIN_PASSWORD` | 管理者の画面を開く合言葉（長めの文字列） |
| `TURSO_DATABASE_URL` | Turso のデータベースの接続先（`libsql://` で始まる） |
| `TURSO_AUTH_TOKEN` | Turso のトークン |

- Turso が未設定だと、報告はサーバーの中のファイル（`./data/feedback.db`）に保存されます。Render ではサーバーが入れ替わると消えるため、公開先では Turso を設定してください。管理者の画面にも注意が出ます。
- 保存するのは、迷った用語・AIの言い換え・理由・前後の短い文だけです。説明の全文、ペットや利用者の情報、IPアドレスは保存しません。
